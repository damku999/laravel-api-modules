# Upgrade Guide

## 1.x to 2.x

**No breaking changes yet.**  
Follow the releases and CHANGELOG for upgrade steps as new versions are released.

## General Upgrade Tips

- Review the [CHANGELOG.md](CHANGELOG.md) after updating.
- If new traits or helpers are added, re-run the module generator to auto-publish them to your app.
- After upgrading, compare your published config/stubs with the latest package versions and merge changes as needed.
