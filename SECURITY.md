# Security Policy

## Supported Versions

We release patches for supported versions. Please refer to the repository documentation for currently supported versions.

## Reporting a Vulnerability

If you discover a security vulnerability, please do the following:

- **Do not** create a public issue for the vulnerability.
- **Report it privately** by emailing us at **darshan@webmonks.in**.
- Please include as much information as possible to help us investigate and fix the issue quickly (e.g., steps to reproduce, affected version, etc.).

We will acknowledge your report within 3 business days and will work with you to resolve the issue promptly. We appreciate responsible disclosure and will credit you as appropriate.

## Additional Information

For general questions about project security, please open an issue (without sensitive details) or contact the maintainers.

Thank you for keeping our project and community secure!
